# Security policy

Please report security problems privately to **security@killbottleneck.com** — not in public issues.
We reply within a few working days and credit reporters who want it.

## In scope

The Windows app itself: what a page from a (possibly hostile) server can make the app do, links and
protocols that leave the app, permissions, the update channel, the installer and anything stored in
`%APPDATA%\killBottleneck`.

## Out of scope here

Problems of the killBottleneck web application or server (the pages the window shows) — report them
the same way; they are fixed in killBottleneck itself, not in this app.

## Supported versions

Only the latest release. The app updates itself; please make sure you run the newest version before
reporting.
